# Getting help

| You have | Go to |
|---|---|
| A question ("why is my run list empty?", "how do I…?") | [GitHub Discussions](https://github.com/tomeyer97/zerochat/discussions) |
| A bug | [New issue → Bug report](https://github.com/tomeyer97/zerochat/issues/new/choose) |
| A feature request | [New issue → Feature request](https://github.com/tomeyer97/zerochat/issues/new/choose) |
| A security problem | [SECURITY.md](SECURITY.md): report it privately, never in a public issue |
| A problem in Zeroshot itself | Zeroshot's own project ([`@the-open-engine-company/zeroshot`](https://www.npmjs.com/package/@the-open-engine-company/zeroshot)); zerochat is an independent project |

Before you ask, run `zerochat doctor`: it checks Zeroshot, its state directory, zsf and pb, and says what
is wrong. Paste its output in your question or bug report.

## What to expect

- One volunteer maintainer ([MAINTAINERS.md](MAINTAINERS.md)): help is best effort.
- Issues and discussions get a first response within 7 days.
- Supported: the latest 0.x release, on Linux and macOS. Windows: use WSL.
